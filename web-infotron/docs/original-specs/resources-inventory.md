Notes:
- Every board decodes with Murphy walk icon **198** stored at the exact
  `murphy` header position (a strong end-to-end validation of the decoder).
- Levels use hardware variants **758–760**, which are *outside* the
  classifier’s 750–757 hardware range — they classify as the inert generic
  piece, which is behaviorally identical (indestructible, not rounded).
- Level 31 “Seeing Yellow” really is 120×120: its designer painted the full
  board, and FixSize cannot trim because row/col 2 end in empty (129), not
  base (128).
- The raw (pre-FixSize) size is 120×120 for every level; the editor always
  saved full boards and the engine trims at load.
- Level 31 is also the only level whose border ring is not fully hardware:
  its extreme bottom-right corner cell (120,120) is base 128 (destructible
  by an adjacent explosion). Murphy can never occupy a corner, but a port
  that reads out of bounds instead of trusting borders should know the ring
  is not literally solid there.

## Re-running the pipeline

```sh
cd web-infotron
pnpm assets            # = node scripts/build-assets.mjs
# or directly:
node scripts/extract-resources.mjs
```

Requires: `unar` (`brew install unar`), ImageMagick at
`/opt/homebrew/bin/magick` (with `sips` as fallback), and the repo dev
dependencies (`pnpm install`; uses `jimp`). Outputs go to `public/assets/`;
the extraction cache lives in `.assets-cache/` at the web-infotron root.
